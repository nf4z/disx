# External services

The application, database, gateway, voice SFU, account verification, encryption and pride artwork run locally. Cap signup verification is embedded and self-hosted; it does not call trycap.dev.

GIF search is an explicit exception to the local operation policy. It has its own enable switch in **Admin → Site settings → GIF search**; enabling it does not enable unrelated integrations. Klipy is the default, with an operator-supplied key. Users can select Klipy or Tenor in the native GIF picker. Keys are stored in instance configuration and never returned by the settings API; blank inputs preserve an existing key and the remove checkbox deletes it. Configuration changes take effect immediately.

Discord telemetry/Sentry endpoints are disabled in the local client bootstrap; they are not a required service.

## GIF verification and upstream limits

A bounded direct request to the exact public key and `https://api.tenor.com/v1/search` used by the checked-in Vencord source returned **HTTP 200 with two results on October 4, 2026**. The Tenor provider genuinely uses Tenor; it is not redirected to Klipy. Google nevertheless [announced API retirement for June 30, 2026](https://support.google.com/tenor/answer/10455265), so this observed compatibility endpoint is not a guarantee of ongoing service.

Klipy's [official API documentation](https://klipy.com/docs) and [partner panel](https://partner.klipy.com) describe key setup. Without a configured instance key, live Klipy search cannot be verified. Provider tests cover shape conversion, selected format, locale/format cache isolation, bounds, missing-key handling, safe failure messages and genuine provider selection. Neither provider silently substitutes results from the other.
