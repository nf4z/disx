# Pride badge artwork

The picker includes **all 40 flags** from [b3yc0d3/twemoji-flags](https://github.com/b3yc0d3/twemoji-flags), pinned to commit `1eee036f2567edc1f56f7dcb4105eae5a347cc7b`, plus **10 supplemental flags**. All 50 are local SVGs; selecting or displaying a badge makes no external artwork or API request.

The authoritative snapshot is `assets/badge-icons/twemoji-flags/manifest.json`. It records each upstream filename, local slug/icon mapping, SHA-256 checksum, the commit, and the graphics license. The source directory contains 40 actual flag SVGs and `TEMPLATE_FLAG.svg`. The latter is an authoring template, excluded from selectable flags by the upstream build as well as this instance. The original SVGs, template, README, and both upstream licenses are vendored alongside the manifest. Graphics are licensed under CC BY 4.0; the upstream software license is MPL 2.0, and no upstream build code is used here.

The 40 upstream flag images are copied without modifications. The 10 supplemental images use the exact upstream template silhouette, with locally drawn stripes and symbols. The template is a rounded flag occupying a 36-by-26 area on a 36-by-36 canvas. The intersex-inclusive Progress circle remains circular and wholly within the yellow chevron. Attribution appears in the picker and in [the vendored attribution file](../assets/badge-icons/twemoji-flags/ATTRIBUTION.md).

All previous 33 flag slugs and badge IDs are preserved. Twenty-three now use matching upstream artwork, and 17 new upstream choices are appended. The 10 supplemental choices preserve flags absent from that upstream snapshot: rainbow, original eight-stripe rainbow, Philadelphia, intersex-inclusive Progress, seven-stripe lesbian, five-stripe gay men, gray-asexual, grayromantic, unlabeled, and androgyne. These remain selectable; no database migration or automatic selection deletion is needed. Stored unknown selections are returned unchanged to their owner, and saving an unknown slug fails validation rather than silently dropping it.

The five- and seven-stripe lesbian/gay-men variants remain distinct. Bisexual stripe proportions are 40:20:40 in the upstream art; androgyne has vertical stripes. Supplemental palette references include [Gilbert Baker's rainbow history](https://gilbertbaker.com/rainbow-flag-origin-story/), [Valentino Vecchietti's intersex-inclusive Progress flag](https://www.intersexequality.com/intersex-inclusive-progress-pride-flag/), [AUREA's aromantic resources](https://www.aromanticism.org/en/resources-1), [AVEN's asexual flag reference](https://wiki.asexuality.org/w/index.php?title=Asexual_flag), and [Microsoft's community pride flag references](https://github.com/microsoft/Pride). Their images are references for the locally drawn supplemental designs; their artwork is not vendored.

Run `node scripts/pride-badge-art.cjs` to reproduce local badge images offline from the pinned originals and template. Run `node scripts/pride-badge-art.cjs --check` and `node --test scripts/tests/pride-badges.test.cjs scripts/tests/pride-badge-art.test.cjs scripts/tests/pride-profile-refresh.test.cjs` to verify completeness, checksums, rendering, preserved IDs, selection validation, and profile refresh coalescing. The browser smoke test derives its expected count from the manifest and checks all 50 images, persistence, cached friend updates, clearing, search, and preservation of admin-assigned badges.
