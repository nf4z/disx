# Twemoji flags artwork

Artwork by b3yc0d3 and contributors from [twemoji-flags](https://github.com/b3yc0d3/twemoji-flags), pinned to commit `1eee036f2567edc1f56f7dcb4105eae5a347cc7b`. The 40 SVGs are copied without modifications and licensed under [CC BY 4.0](LICENSE-GRAPHICS). The upstream software license is preserved in [LICENSE](LICENSE); no upstream build code is used.

The manifest records every source SVG, local badge mapping, and SHA-256 checksum. `TEMPLATE_FLAG.svg` is an empty authoring template and is excluded, as in the upstream build. Ten additional locally drawn flags derive their silhouette from the pinned upstream template, adapted with stripes and symbols to preserve existing selections. These adapted graphics retain CC BY 4.0 attribution; the manifest identifies them separately from the 40 unchanged upstream flag images.
